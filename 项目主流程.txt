下面按“巡检发现问题 → 自动对表分级 → 派单跟踪 → 证据验证防假改 → 复查关闭”这条主线出图。核心是把**你现在的三个手工痛点**变成三个Agent职责：条款映射（不用再对着表查）、风险分级（减少人为分级错误）、证据验证（防口头答应和表上假改）。

### 节点职责与对应痛点

| Agent / 节点 | 解决你哪个痛点 | 关键设计 |
|---|---|---|
| **巡检录入Agent** | 巡检记录零散、口语化 | 语音/照片转结构化问题单：位置、现象、时间、涉及工序、初判类别 |
| **条款映射Agent** | “问题和HACCP对不上、对着表查好久” | RAG检索HACCP/法规/SOP，返回**Top-N条款+原文片段+置信度**；低置信度不硬猜，转人工选，选择结果回流做样本 |
| **风险分级Agent** | “人为分级容易错” | 规则优先（是否CCP偏离、是否过敏原/异物/微生物、是否批量）→ LLM补充理由；输出**分级+依据条款+理由**，A级和低置信度强制人工确认 |
| **整改派单Agent** | 责任不清、口头答应 | 整改单强制包含：责任人、时限、**所需证据类型清单**（照片/记录/复检数据/校准证书） |
| **跟踪升级Agent** | “改正不及时” | 整改时钟不可关闭；超时按级自动上推；**打回不重置倒计时** |
| **证据验证Agent** | **“表上写改了其实没改”** | 四道校验：清单完整性→元数据时间→历史复用检测→语义核验；A级/CCP相关强制人工现场确认 |
| **复查抽验Agent** | 纸面闭环 | 按比例**不预先通知**现场复查；复查不通过等同无效整改 |
| **CAPA联动** | 同类问题反复 | 30天内同类复发自动升级CAPA，并触发HACCP计划评审 |

### 防假改的四条硬规则（图2的核心）

1. **证据类型由问题类型决定，不由整改人自选。** 例如“地面积水”要求整改后照片+清洁记录；“温度记录缺失”要求温度仪导出文件+校准状态截图。缺项直接打回。
2. **证据必须“新鲜”。** 校验拍摄时间/EXIF是否在派单之后、关闭之前；疑似旧图直接打回。
3. **历史复用检测。** 对照片做哈希和相似度比对，防止拿上次整改的照片重复交。
4. **打回不重置倒计时。** 这是防拖延的关键——口头答应、交假证据，时间照样在走，超时照样升级，无效整改次数单独统计并进入责任部门绩效。

---

1. **复查抽验比例**：建议A级100%现场复查，B级30%—50%，C级10%—20%，你可以按工厂人力量力定。
2. **条款映射置信度阈值**：低于阈值转人工。
