下面是一份可直接拿去和开发/技术供应商对齐的**最小系统规格说明**。原则先写在前面：**规则负责判定与闸门，LLM负责抽取、检索、解释和证据语义核验，人工保留分级确认、A级/CCP现场复核和最终关闭签字**。所有Agent输出必须结构化，所有状态转换必须留审计记录。

---

## 一、系统边界与设计原则

- **范围**：巡检发现→问题单→条款映射→风险分级→派单→整改跟踪→证据验证→复查→关闭/CAPA联动。
- **不替代**：HACCP计划的制定与评审、食品安全授权人的停线/拒收/放行决策、现场物理检查本身。
- **硬约束**：
  1. 低置信度条款映射不得自动定级，必须转人工选条款。
  2. A级问题和CCP相关问题不得仅凭照片自动关闭，必须人工现场复核。
  3. 打回整改不重置倒计时；无效整改次数单独累计。
  4. 所有LLM输出带来源引用或明确标注“模型建议”，人工修改留痕。

---

## 二、核心数据模型：问题单字段

| 字段组 | 字段 | 说明 |
|---|---|---|
| 标识 | 问题单ID、巡检任务ID、发现时间、发现人、区域/工位 | 自动生成，不可改 |
| 现象 | 原始输入（语音转写/照片/文字）、结构化现象描述、涉及工序、涉及批次/设备 | 录入Agent抽取，人工可修正 |
| 条款 | 映射条款ID、来源文件、版本、原文片段、置信度、备选条款Top-N | 映射Agent输出，人工确认后锁定 |
| 分级 | 等级A/B/C、分级依据（规则命中项/LLM理由）、确认人、确认时间 | A级强制人工确认 |
| 整改 | 责任人、责任部门、时限、所需证据类型清单、整改要求 | 派单Agent生成，可人工调整 |
| 跟踪 | 当前状态、倒计时截止、升级记录、打回次数、无效整改次数 | 系统维护 |
| 证据 | 证据列表（类型、文件、拍摄时间、哈希、验证结果） | 验证Agent写入 |
| 关闭 | 复查人、复查方式、复查结果、关闭时间、CAPA关联ID | 人工签字关闭 |

## 三、Agent规格

### Agent 1：巡检录入Agent

- **输入**：语音、照片、文字备注、巡检路线/工位信息。
- **输出**：结构化问题单草稿（现象描述、区域、工序、初判类别、建议证据类型）。
- **实现**：ASR + 多模态抽取（可用小模型/VLM），输出经Pydantic schema校验；抽取置信度低的字段标黄，要求巡检员确认。
- **人工点**：巡检员提交前确认/修正现象描述和区域。

### Agent 2：条款映射Agent（解决“对不上HACCP、查表慢”）

- **知识库**：HACCP计划（CCP/CL/监控程序/纠偏）、SSOP、GMP、供应商验收标准、清洁消毒SOP、异物防控程序、标签法规。**按条款级分块**，每块保留：条款编号、来源文件、版本、生效日期、原文、适用区域/工序。
- **检索**：向量检索 + BM25混合，先按区域/工序做元数据过滤，再召回Top-10，rerank取Top-5。
- **输出**：每条候选含条款ID、原文片段、来源、置信度、匹配理由。
- **阈值规则**：
  - 置信度 ≥ 高阈值（建议初始0.75）：可预填，仍允许人工改。
  - 中阈值（0.5—0.75）：展示Top-3，**必须人工选**。
  - 低于0.5：不预填，提示“未匹配到可靠条款”，转人工并从候选列表选择或新建条款映射。
- **回流**：人工最终选择的条款与现象描述存入映射样本库，用于后续调阈值和few-shot示例；不自动训练，先离线评估。
- **人工点**：条款确认。

### Agent 3：风险分级Agent（解决“人为分级容易错”）

**确定性规则优先**，LLM只做边界情况建议和理由生成。建议规则表：

| 命中条件 | 建议等级 | 是否强制人工确认 |
|---|---|---|
| CCP偏离/关键限值超限 | A | 是 |
| 过敏原交叉污染风险、致病菌指示、异物进入产品风险 | A | 是 |
| 批量性/系统性缺陷（同区域同问题≥3例或跨批次） | A | 是 |
| 冷链温度断链、清洁消毒失效且已接触产品 | A | 是 |
| 记录缺失但可通过复检/追溯补证 | B | 否（可抽确认） |
| 一般卫生、标识、人员着装、局部积水 | B/C | 否 |
| 同类问题30天内复发 | 在原等级上至少升一级 | 是（若升至A） |

- **LLM角色**：在规则未命中或规则冲突时，基于现象描述和条款原文给出**建议等级+理由+引用条款**，不得单独把问题定为A级；A级必须人工确认。
- **输出**：等级、命中规则/LLM理由、依据条款、置信度、是否需人工确认。
- **人工点**：A级确认、低置信度确认、等级调整留痕。

### Agent 4：整改派单Agent

- **输出整改单必填项**：问题描述、条款依据、等级、责任人/部门、整改时限、**证据类型清单**、复查方式。
- **证据清单按问题类型模板化**（示例）：

| 问题类型 | 必交证据 | 可选/交叉校验 |
|---|---|---|
| 温度记录缺失/断链 | 温度仪导出文件、校准状态截图、补录说明 | 冷库日志、设备运行记录 |
| 清洁不彻底/积水 | 整改后照片（含时间水印）、清洁消毒记录 | 环境采样结果（如适用） |
| 人员卫生/着装 | 整改后现场照片、班前会记录 | 监控抽查记录 |
| 异物风险（破损工具/包装） | 更换后照片、破损工具报废记录 | 金属探测/X光记录 |
| 标签标识错误 | 更正后标签照片、批次隔离/返工记录 | 放行记录 |
| 虫害设施异常 | 设施修复照片、虫害检查记录 | 服务商报告 |

- **规则**：证据类型由问题类型+等级决定，整改人不能自选删除必交项；缺项在验证环节直接打回。

### Agent 5：跟踪升级Agent（解决“改正不及时”）

建议默认时钟（需业务确认后固化）：

| 等级 | 首次响应 | 整改完成时限 | 超时升级路径 |
|---|---|---|---|
| A | 30分钟内确认接收 | 24小时（临时遏制）/ 72小时（根因与CAPA草案） | 班组长→车间主任→厂长/质量总监 |
| B | 2小时 | 3个工作日 | 班组长→车间主任→质量经理 |
| C | 24小时 | 7个工作日 | 班组长→车间主任 |

- **硬规则**：打回不重置倒计时；无效整改次数+1；超时自动推送，不依赖人工催办；升级记录进入责任部门月度统计。
- **人工点**：责任人可申请延期，但延期需质量授权人批准并留痕，A级原则上不允许延期。

### Agent 6：证据验证Agent（解决“口头答应、表上假改”）

四道校验，按顺序执行：

1. **清单完整性**：必交证据是否齐全；缺项→打回。
2. **元数据校验**：照片EXIF/拍摄时间是否在派单之后、提交之前；定位是否在厂区/相关区域；时间不符或疑似旧图→打回。
3. **历史复用检测**：文件哈希 + 图像相似度比对历史证据库；高度相似→打回并标记“疑似复用”。
4. **语义核验**：VLM/规则判断证据内容是否对应整改项（如“地面积水”整改后照片应显示干燥地面）；明显不符→打回。VLM只做**辅助判断**，输出“符合/不符/存疑”，存疑转人工。
5. **交叉校验**：关联记录/复检数据/设备日志是否一致；矛盾→存疑转人工。

- **分流规则**：A级/CCP相关→无论自动结果如何，**必须人工现场复核**；B/C级自动通过后进入复查抽验。
- **打回后果**：无效整改次数+1，倒计时继续，记录进入责任部门绩效。

### Agent 7：复查抽验与CAPA联动Agent

- **复查比例建议**：A级100%现场复查；B级30%—50%；C级10%—20%。复查**不预先通知**现场。
- **复查不通过**：等同无效整改，打回重开，累计次数。
- **复发判定**：同一区域/工序/条款，30天内同类问题再次出现→自动升级为CAPA，并触发HACCP计划/SSOP评审提醒。
- **关闭**：复查通过后由质量授权人签字关闭；关闭后更新条款映射样本库和问题趋势看板。

## 四、状态机与审计

**问题单状态**：草稿→待映射→待分级确认→待整改→待验证→待复查→已关闭；旁路状态：打回重开、存疑复核、升级CAPA、延期审批中。

**每次状态转换必须记录**：操作人/Agent、时间、输入输出摘要、置信度、人工修改前后值、引用来源、Agent版本。审计日志不可编辑，仅可追加。

---

## 五、上线前必须做的离线评测

1. **条款映射**：用历史巡检记录构造100—200条样本，人工标注正确条款，评估Top-1/Top-3准确率和低置信度转人工比例；据此调阈值。
2. **分级一致性**：抽50—100条历史问题，由质量专家重新分级，与规则+LLM建议对比，重点看A级漏判和过度升级。
3. **证据验证**：构造“真整改/假整改/旧图复用/证据不全”四类样本，评估打回准确率和误杀率；VLM存疑比例过高时先只做规则校验。
4. **时钟与升级**：用模拟数据跑一遍超时升级路径，确认通知可达、升级不依赖单人。

---

## 六、需要业务方拍板的参数清单

1. 条款映射高/中置信度阈值（建议先0.75/0.5，用评测调）。
2. A/B/C三级整改时限和首次响应时限。
3. 复查抽验比例。
4. 同类问题复发判定窗口（建议30天）和“同类”的定义粒度（区域+工序+条款）。
5. A级/CCP人工现场复核的授权人名单。
6. 延期审批权限：谁能批、A级是否允许延期。
7. 无效整改次数是否进入绩效、阈值多少触发约谈。
